# Spec

## window

用滑鼠滾輪縮放
用滑鼠中鍵拖曳畫面
遊戲整體用2d地圖呈現3d效果
物體的基準點的y座標決定顯示順序，越下方越靠近玩家，會顯示在越上層
物體滯空時影子縮放呈現高度變化

## map struct

2d grid map，可以設定長寬，預設先用16x9格，零點在左上角
每格大小可設定，預設先用25x25 pixel
格子為空時顯示為純白方形
格子有牆時，顯示為純黑方形，預設把地圖最外圈圍住，只留內部14x7格可活動

## character

角色位置基準點用一個(x,y)決定，以此為中心碰撞判定可以設定長寬，預設先用9x9 pixel
角色顯示時用一個sprite，大小可設定，預設先用25x25 pixel
角色腳底用灰色橢圓顯示影子，大小可設定，預設先用11x7 pixel
角色sprite顯示順序在影子上
角色飛空時影子會縮小，落下時影子放大，落地後影子會復正常
角色與牆有判定，不可通過
預設先設定一個玩家角色在地圖上，在座標1x1

## trap

### 共通設定

- 角色最後的移動方向為面朝方向，角色四周顯示一個紅色三角形指示面朝方向
- 設置陷阱時，顯示指向箭頭到目的地
- 若指向箭頭遇到地圖邊界或 wall block，則不允許設置 block
- 滑鼠放開時 block 消失（設置失敗）

### Guilty Lance

藍色 block，可從遠處把敵人抓到近處。

**外觀**：藍色方形 block

**設置方式**：
- 拖曳 block 到 grid map 上
- 顯示指向箭頭，箭頭由起點指向 block 自身作為目的地
- 預設箭頭從 block 右邊的第 1 格為起點，指向 block 自身
- 可用滑鼠滾輪一次旋轉 90 度，改變箭頭方向
- 如果指向路徑（起點到 block 之間）遇到地圖邊界或 wall block，不允許放置

**CD 時間**：設置後 5 秒

**觸發效果**：
- 讓起點 cell 裡的 enemy 進入「被強制移動」的狀態
- 造成 40 點傷害
- 強制移動時 enemy 飛向目的地（block 所在位置）
- 飛行速度：0.25 秒 / 格
- 到達目的地後 enemy 進入「倒地」狀態 2 秒（不可移動）
- 倒地結束後繼續追擊玩家角色
