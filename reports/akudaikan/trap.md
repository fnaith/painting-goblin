## 欄位說明

| 欄位 | 說明 |
|------|------|
| 名稱 | 陷阱名稱（日文原名） |
| 設置 | 安裝位置：天井・壁・床 |
| 効果 | 特殊效果。強制移動Nブロック＝強制移動N格；拘束N秒＝束縛N秒；吸引N秒＝吸入N秒 |
| DMAGE | 傷害值 |
| CHARGE | 充填時間（秒） |
| ARK | Ark係數（影響連鎖分數倍率） |
| 殘虐／華麗／屈辱 | 該分類對應的點數 |
| 備註 | 入手條件或特殊備註。ch=章節，DLC=付費下載內容 |
