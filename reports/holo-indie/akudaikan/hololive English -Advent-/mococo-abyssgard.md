# Mococo Abyssgard 主題陷阱設計

> 基於《影牢4 暗黑公主》陷阱系統，結合 Mococo Abyssgard（惡魔看門犬／毛茸茸的搗蛋鬼）角色特質設計
> 設計方針：以「搗蛋鬼（Mischievous）」、「毛茸茸（Fuzzy）」、「看門犬（Guard Dog）」三大核心元素貫穿所有陷阱

---

## 設計總覽

### 設計核心概念

| Mococo 特質 | 陷阱設計應用 |
|-------------|-------------|
| 惡魔看門犬（Demonic Guard Dog） | 犬牙、地獄犬、吠叫音波、看門犬領域等意象 |
| 毛茸茸（Fuzzy / もふもふ） | 絨毛球、毛毯、毛茸手掌等柔軟素材轉化為陷阱 |
| 搗蛋鬼（Mischievous） | 香蕉皮、睡衣變裝、強制擊掌等惡作劇型陷阱 |
| 雙子羈絆（FUWAMOCO） | 雙重攻擊、同步節奏、姐妹連攜意象 |
| 監獄逃脫（Prison / The Cell） | 監獄鏡面、鎖鏈拘束、深淵之門等視覺元素 |
| 偶像（Idol） | 舞台、魔法陣、閃亮效果等華麗要素 |
| Pero（寵物） | 寵物造型彈跳墊、動物夥伴輔助攻擊 |
| 泡澡／毛毯（Bath / Blanket） | 浴缸滑倒、毛毯捆綁等舒適轉屈辱的陷阱 |
