# Hakos Baelz 主題陷阱設計 — 《影牢》風格陷阱案

> 設計基準：Hakos Baelz（Hololive English -Promise-）
> 主題元素：混沌（Chaos）、老鼠（Rat）、骰子（Dice）、芝士（Cheese）、倒置文字（Upside-Down Text）、澳洲文化、咖啡、BaeRyS

---

## 一、壁陷阱（Wall Traps）

### 1.1 殘虐（Cruelty）

#### カオスラットウォーム — Chaos Rat Swarm

| 欄位 | 內容 |
|------|------|
| 名稱 | カオスラットウォーム（Chaos Rat Swarm） |
| 類型 | 壁 |
| 分類 | 殘虐 |

| 欄位 | 內容 |
|------|------|
| 名稱 | ダイスニードルマット（Dice Needle Mat） |
| 類型 | 床 |
| 分類 | 殘虐 |
| 説明 | 地板升起一塊巨大的骰子面形狀的釘板，每面的釘子排列方式對應骰子點數（1點＝中央1根大釘，6點＝6根中型釘）。踩中後根據骰面數字造成不同傷害和出血效果。防禦力無視。 |
| 備註 | 將骰子點數轉化為地刺排列——這是對Baelz核心象徵最直接的暴力詮釋。點數越多傷害範圍越廣，但單點穿刺傷害最高。混沌的隨機性讓受害者無法判斷踩到的是哪一面。 |
