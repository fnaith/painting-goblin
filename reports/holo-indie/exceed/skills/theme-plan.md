# 設計 Exceed Hololive 同人遊戲主題（Theme）

本 skill 引導你為 Hololive 的各個同期（generation）設計 Exceed 對戰主題。每個主題代表一個獨立季節玩法，同期每位成員各有一張主題卡。

## theme.md 結構

```
# hololive <Generation> — <主題名稱> 規劃
## 參考概念（設計靈感來源）
## 主題設計1
### 核心機制
### 角色對應與各自專屬效果（成員 → 稱號 → 主題零件
### 平衡設計
### 確保擴展性
## 主題設計2
### 核心機制
### 角色對應與各自專屬效果
### 平衡設計
### 確保擴展性
...
```

## 設計流程

### Step 1：收集同期成員資料

讀取同期每位成員的報告與組合資料：

- `reports/holo-indie/exceed/<generation>/` — 讀取<generation>底下的<id>.json，<id>除了theme以外都是角色id
- `reports/holo-member/<id>/report.md` — 每位成員的官方人設、迷因、軼事、人際關係
- `reports/holo-indie/holo-unit.md` — 官方組合／粉絲組合／聯動群組（找尋同期專屬的集體迷因）

從資料中整理：
- 每位成員的核心人設（種族、職業、世界觀）
- 每位成員的招牌迷因（台詞、行為、外號、趣聞）
- 同期專屬的集體記憶（組合名稱、共同事件、粉絲文化）

### Step 2：設計5個核心機制

#### 核心機制選擇

- 找到這個同期**獨一無二**的集體迷因或連結，作為主題的核心。好的核心概念範例：
    - **2nd Gen**：五位成員被比擬為遊戲王黑暗大法師（Exodia）的五張封印卡——「全員齊聚比召喚 Exodia 還稀有」的迷因（記載於 holo-unit.md）
    - **5th Gen**：團體名「NePoLaBo」正是四位成員名字的連結（Ne-ne＋Po-lka＋La-my＋Bo-tan），且由座長ポルカ親自命名
- **避免**：只套用常見框架（學園、電競、祭典）而沒有同期獨特的連結。主題必須從同期自己的故事長出來。
- 根據同期專屬的核心概念，參考遊戲王或MTG的套牌機制，設計能運作於Exceed的主題機制。
- 不使用 Gauge／Force／Exceed／Character Cards／Additional Cards 機制

#### 主題零件的角色對應

將核心概念化為每位成員的「主題零件」，讓每位成員既是核心機制運轉的核心、又有自己的專屬效果：

- 2nd Gen：五張封印卡各對應一個部位（頭部／右腕／左腕／右腳／左腳），每張附帶自己的檢索／防禦機制
- 5th Gen：四位成員化為天氣妖精（雨女／水神／雪女／100℃），各自的 boost 效果依「NePoLaBo 卡數量」等比強化

**成員卡設計要點**：
- 數值刻意弱化（Power 1-2），主要價值在主題機制，避免單卡過強
- 每張卡融入該成員的招牌迷因（台詞、外號、行為）作為 boost 名稱與效果意象
- 每張卡附帶「抽濾／檢索」等輔助手段，讓集結過程有節奏

#### 平衡設計與防呆

設計時主動找出以下問題，並在 theme.md 中記錄解法，範例如下：

1. **「湊滿即勝」太強？** → 加入頭部弱化、零件需配合、受擊展示手牌、棄牌反制、過於強力的終局改用「持續壓制」而非直接勝利
2. **效果互相循環？** → 加入限制：同名一回合一次、需要特定觸發條件（如命中）、同時觸發時的處理規則
3. **Exceed 既有機制** → 善用 Seal（封存）區、Discard（棄牌）區、Boost 區等既有區作為機制核心，別重造輪子

#### 確保擴展性

確認有輔助機制能強化主題機制的運轉

- 2nd Gen：湊齊五張封印卡條件條件勝利，用抽濾機制輔助
- 5th Gen：可因Seal回到boost區，用Seal代價卡牌輔助

## 產出 theme.md

產出主題設計文件到: `reports/holo-indie/exceed/<generation>/theme.md`
