## 一、核心角色概念

**「ゆるふわ脳筋女騎士」（鬆軟 fluffy 的肌肉腦女騎士）**

諾艾爾是一名騎士團長，為了變強而來到VTuber界修行。雖然外表是全副武裝的騎士，但實際上是個溫柔、隨和又有點天然呆的女性。她的最大特徵是——無論遇到什麼問題都想靠肌肉（蠻力）解決。

> 官方介紹：「All hustle, all muscle! Shirogane Noel's here! 這個鬆軟的肌肉腦騎士雖然看起來隨和，卻有著試圖用肌肉力量解決所有問題的危險習慣。」

### 角色核心賣點：外表與內心的反差

| 外表（遊戲角色形象） | 真實性格 |
|---------------------|---------|
| 威嚴的鎧甲騎士團長 | 溫柔、溫暖的女人 |
| 肌肉發達的強大戰士 | 天然呆、隨和、有點笨 |
| 凜然的領袖人物 | 大姊姊型的照顧者 |
| 勇猛的戰士 | 喜歡放鬆聊天和ASMR |

**這個反差就是她角色的核心魅力。**

## 二、個性完整分析

### 主要性格特質

| 特質 | 說明 |
|------|------|
| **溫柔體貼（デレデレ）** | 給人溫暖安心的感覺。直播時語氣柔和、有耐心，是自然的大姊姊類型 |
| **固執有毅力** | 一旦決定要做某事就會堅持到底。著名的耐久直播（Getting Over It 連續挑戰數小時）就是最佳例子 |
| **天然呆／肌肉腦** | 官方認證的「フワフワ脳筋」。容易犯傻，總想用蠻力解決問題 |
| **容易嫉妒／感情豐富** | 對於在乎的人（尤其是Flare）會表現出強烈的情感反應，包括吃醋、流淚、撒嬌 |
| **放鬆悠閒** | 談話台節奏緩慢、氣氛放鬆，適合沉浸式觀看 |

### 角色成長潛力（適合遊戲劇本）

1. **外表堅強內心柔軟的衝突**：騎士必須保護夥伴，但其實內心敏感脆弱
2. **嫉妒劇情線**：與Flare相關的情感糾葛
3. **證明自己**：雖然天然呆，但渴望變強、證明自己的價值
4. **牛丼執著**：可作為搞笑支線/彩蛋
5. **不放棄的精神**：無論失敗多少次都會站起來繼續

## 六、著名梗與軼事（適合遊戲彩蛋）

### 經典事件

1. **Getting Over It 耐久傳說**
   - 挑戰這款出名的整人遊戲，第一次失敗後又開「復仇耐久」
   - 花了數小時堅持通關，成為她毅力的代表作

2. **ASMR內容被下架**
   - 曾是Hololive主要ASMR直播者
   - YouTube政策緊縮導致大量ASMR影片被刪除

3. **房間很亂的梗**
   - 粉絲透過マシュマロ提問多次提到她房間很亂
   - 成為粉絲之間的固定笑點

4. **自認唱歌不好聽**
   - 雖然說話聲音好聽，但對自己的歌聲沒自信
   - 曾分享聲樂老師給她的評價，展現謙虛與努力的一面

## 八、同人遊戲設定建議

### 角色職業定位
- **職業**：騎士／聖騎士（坦克型角色）
- **獨特技能**：
  - 「マッスルメトロノーム」（Muscle Metronome）——高速肌肉抖動攻擊
  - 「鉄の胃袋」——可以吃任何東西回血
  - 「ASMRボイス」——範圍回復／冷靜效果
  - 「耐久の精神」——越戰越強，隨著戰鬥時間增加攻擊力

### 劇情建議
1. **主線**：騎士團長帶領夥伴尋找「最強的力量」，但過程中必須面對自己的內心脆弱
2. **支線**：尋找美味的牛丼——穿越各個城鎮尋找終極牛丼食譜
3. **羈絆事件**：與隊伍中的精靈成員（Flare位）互動，展現情感上的依賴與嫉妒
4. **搞笑事件**：試圖用肌肉解決所有問題卻失敗的各種場景
