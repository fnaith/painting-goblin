## 二、角色設定（Lore）

心懷音樂夢想的少女。官方描述她的生活如同樂曲一般有起有伏，音樂始終陪伴在身邊。性格直率，對熱愛的事物能投入驚人努力，對不喜歡的東西則立刻露出孩子氣的厭惡表情——但有好吃的就能被收買。

出道簽名台詞：
> ドレミファソラティドー！ホロライブDEV_ISから、ReGLOSSの音楽家志望、音乃瀬奏です！
> （Do-Re-Mi-Fa-So-La-Ti-Do！來自hololive DEV_IS，我是ReGLOSS的音樂夢想家，音乃瀬奏！）

設定關鍵詞：
- **音樂家志望** — 核心身份，歌枠是直播主軸
- **喜怒形於色** — 情緒完全寫在臉上，毫不掩飾
- **孩子氣** — 討厭的事會直接皺眉，但容易被食物收買
- **努力家** — 對喜歡的事能投入驚人努力

遊戲設計提示：這是一個「直率努力家」型角色，適合設計成音樂/節奏主題的角色，情緒反饋直接誇張。

## 四、個性特徵

### 核心性格

| 特質 | 描述 | 遊戲化建議 |
|------|------|------------|
| **精力充沛** | 極度元氣，充滿活力的大喊和自我介紹 | 移動/待機動作可設計成雀躍跳動 |
| **小惡魔/屁孩** | 喜歡惡作劇、捉弄人，說話直來直去 | 對話選項可設計調皮/搗蛋路線 |
| **喜怒形於色** | 開心大笑、不開心直接皺眉，毫不掩飾 | 表情變化可做得很誇張，不開心時冒青筋 |
| **努力家** | 耐久歌枠連唱數小時，對音樂極度認真 | 可設計「幹勁」狀態或技能 |
| **直率** | 叫粉絲「おまえら」（你們這幫傢伙），不刻意討好 | 語音風格可偏向朋友互嗆而非溫柔系 |

### 口頭禪與台詞

| 台詞 | 使用場合 |
|------|----------|
| 「こんのせ！（Konnose）」 | 打招呼 — こんにちは + 音乃瀬 |
| 「おつのせ！（Otsunose）」 | 道別 — お疲れ + 音乃瀬 |
| 「またね～～～～～～～～ガハ！」 | 另一種道別，配合大笑 |
| 「かなでスタンバイ🎹✨」 | 待機畫面台詞，遊戲王梗 |
| 「あぁ～！奏の音ォ〜！！」 | 出道直播標題，極具代表性 |
| 「おまえら」 | 稱呼粉絲的口癖 |
| 「ガハ！」 | 招牌大笑聲 |

遊戲設計提示：「こんのせ」和「おつのせ」可直接做為見面/離隊語音。「かなでスタンバイ」可用於載入畫面。

- **歌枠（KARAOKE）：** 核心內容，以耐久歌枠（連續唱數小時）著稱，幾乎所有里程碑都在耐久歌枠中達成

- **原創曲：** Shunkan Heartbeat（出道曲）、Symmetry、GREATEST（首支個人原創）、You & aIzu（第二支個人原創）
- **團體曲：** feelingradation、bubble maybe、Lucky Loud 等

3. **遊戲王知識：** 資深遊戲王粉絲，梗和台詞常出自遊戲王

## 九、遊戲設計整合建議

### 可用角色原型
- **音樂夢想家：** 以唱歌為核心動力的努力型角色
- **元氣屁孩：** 精力充沛、愛捉弄人、情緒外放
- **多語言能力者：** 可自然使用日語和韓語兩種語音

### 可融入的玩法元素
1. **音樂/節奏系統：** 呼應音樂家設定，可加入節奏遊戲或歌唱技能
2. **耐久機制：** 靈感自耐久歌枠——持續進行某項操作時獲得加成
3. **情緒反饋系統：** 開心時大笑、不爽時皺眉，表情隨狀態動態變化
4. **遊戲王梗彩蛋：** 待機/載入畫面顯示「かなでスタンバイ」
5. **「Otonose Monday」彩蛋：** 遊戲內日曆/時間系統觸發特殊對話
6. **1.5倍速彩蛋：** 特定條件下對話加速播放的搞笑選項
7. **被食物收買：** 使用食物道具可快速提升好感度

### 視覺風格參考
- 主色：白、米色、紅、金
- 象徵元素：🎹鋼琴鍵、✨音符、紅蝴蝶結
- 角色主題曲方向：Vocaloid / J-Pop風格
- 服裝設計：音樂學院風水手服 + 西洋外套
