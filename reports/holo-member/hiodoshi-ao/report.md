## 二、官方設定與角色背景

### 官方自我介紹
> 「你以為我是可愛的女孩子嗎？鏘鏘——！是我青君啦！」

### 設定核心
- **表面身份**：喜愛孤獨的漫畫家
- **偽裝人格**：試圖表現得冷酷瀟灑、超然物外
- **真實面貌**：重度御宅族，極度在意他人眼光
- **家中祕密**：外表光鮮亮麗，但家中是「潘朵拉的盒子」（極度混亂）

### 角色關鍵詞
漫畫家 / 假小子（tomboy） / 反差萌 / 眼鏡 / 高挑 / 趕稿地獄 / 獨處至上

## 三、個人特色與直播風格

### 形象特徵
- 藍白主調的漫畫家造型，戴眼鏡，高挑帥氣
- 自稱「青君（Ao-kun）」，帶有男孩風語氣
- 中性沙啞聲線，偶爾露出可愛高音

### 性格特質
- 刻意營造孤高形象，但很容易破功
- 對創作有極高熱情
- 容易害羞，社交能量有限
- 家裡極度混亂的反差萌

### 直播風格
- **#青原稿中**：直播名稱固定使用，意為「青正在趕稿」
- 繪畫實況：展示漫畫/插畫創作過程
- 遊戲實況：偏愛劇情向 RPG、恐怖遊戲
- 雜談閱讀：放鬆聊天、朗讀配信
- 繪圖速度驚人，被稱為「青ペン畫伯」

## 四、知名梗與迷因

### 招牌台詞與用語
| 用語 | 說明 |
|------|------|
| 「青くんでした」 | 招牌結尾，假小子風格的自我介紹 |
| 「カキカキ🖋」 | 待機畫面用語，書寫擬聲詞 |
| 「原稿中です」 | 表示正在趕稿 |

### 經典迷因

1. **帥氣男孩風（tomboy）反差萌**
   - 自稱「青くん」但經常流露可愛一面
   - 粉絲常吐槽「不要裝酷了」

2. **漫畫家 vs 家裡亂（潘朵拉的盒子）**
   - 官方設定明確指出家中極度混亂
   - 粉絲戲稱房間是「核爆現場」

3. **眼鏡是本體**
   - 戴眼鏡是標誌性特徵
   - 粉絲認為拿下眼鏡會變不同人格

4. **171cm 身高霸權**
   - ReGLOSS 中最高（Kanade 153cm、Ririka 160cm 等）
   - 身高差成為 meme 素材

5. **原稿地獄**
   - 經常在直播中崩潰表示還有原稿要畫
   - 粉絲用「加油啊漫畫家！」鼓勵

## 八、粉絲文化

- **Scholars（學者）**：官方粉絲名，呼應知性形象
- **読者（Ao-tomo）**：非正式稱呼，意為「讀者」
- **#青ペン**：粉絲藝術 tag，雙關名字與畫筆
- **#青原稿中**：直播 tag，完美結合漫畫家設定
- 粉絲之間廣為流傳「表面帥氣、私下邋遢」的反差形象

## 九、同人遊戲設定建議

### 推薦角色定位
1. **創作型角色**：以繪畫/漫畫能力為核心技能的藝術家
2. **冷酷帥哥型夥伴**：表面冷漠但其實很關心隊友
3. **反差萌角色**：嚴肅外表下藏著御宅興趣
4. **吐槽擔當**：冷靜客觀的觀察者角色

### 視覺設計要素
- 藍髮 + 眼鏡 + 高挑身形
- 藍色系制服/服裝
- 招牌動作：推眼鏡、拿筆作畫、雙手插口袋裝酷
- 代表道具：畫筆、原稿用紙、眼鏡

### 可融入遊戲的梗
- 趕稿地獄（時間壓力機制）
- 潘朵拉盒子之家（探索/收集要素）
- 眼鏡本體論（裝備/變身系統）
- 171cm 身高差（與其他角色的互動對話）
- 「青くん」自稱（對話選項風格）
