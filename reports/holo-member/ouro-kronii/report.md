## 世界觀設定（Lore）

### 時間看守者（Warden of Time）
- 時間是「一種堅定不移、精確的實體」，其看守者「同樣冷靜且無可挑剔」
- 她是眾神創造的**第三個概念**，也是「與人類最密不可分」的概念
- 原本時間只是「齒輪中的一個零件」，只能與其他概念協同運作
- 人類賦予時間個別意義（黎明、黃昏等），使其成為普遍概念
- 人類因賦予時間力量而反被時間「奴役」
- 在目前的型態中，她被描述為「虐待狂且傲慢的看守者」

### 在Hololive Council / Promise中的角色
- 作為**hololive English -Council-** 的一員出道，五名成員各代表一個基礎概念：
  - Tsukumo Sana — 空間 (Space)
  - **Ouro Kronii — 時間 (Time)**
  - Ceres Fauna — 自然 (Nature)
  - Nanashi Mumei — 文明 (Civilization)
  - Hakos Baelz — 混沌 (Chaos，原初之力)
- 2023年10月9日，Sana畢業後，Council剩餘成員與IRyS合併，組成**hololive English -Promise-**

### 名字由來
- **「Ouro」** 來自 *ouroboros*（銜尾蛇，象徵循環時間／無限）
- **「Kronii」** 來自希臘語 *chronos*（時間）
- 被否決的姓氏 **Gandr** 來自 Jörmungandr（世界蛇，另一個銜尾蛇象徵）

## 性格特徵

### 表面人格
| 特質 | 說明 |
|------|------|
| 自稱「完美」 | 口頭禪：「Kroniichiwa! It's me, perfection.」 |
| 冷靜、沉著 | 深沉的嗓音，沉穩的態度 |
| 自戀 | 毫不猶豫地自我讚美，會開玩笑建議觀眾「just be better」 |
| 傲慢 | 設定中描述她有「一點傲慢和虐待狂的傾向」 |

### 真實面貌（反差萌）
| 特質 | 說明 |
|------|------|
| 很容易慌亂 | 被捉弄時會暴露可愛的一面（gap moe） |
| 運氣極差 | 遊戲中和現實中都笑料百出的壞運氣 |
| 自我苛責 | 常說「that's on me」、「that was my bad」 |
| 反應誇張 | 遊戲中受傷或死亡時會發出爆炸性的叫聲 |

### 性格原型分析
- **Kuudere**（冷酷型）— 表面冷靜、沉穩
- **Tsundere**（傲嬌型）— Hakos Baelz稱她為「tsundere granny」
- **喜劇角色** — 被形容為「酷阿姨」或「引人共鳴的笑料角色」
- **反差萌女王** — 冷靜外表與慌亂內心的反差是粉絲最喜愛的特質

### 喜歡的事物
- 睡覺／小睡、夜間散步、**存在主義恐懼（existential dread）**、游泳、動漫、漫畫、Webtoon

### 討厭的事物
- 睡覺／小睡（矛盾）、拖延症、蔬菜、時間壓力下的工作（對時間看守者而言很諷刺）、讓人暴躁的遊戲

### 口頭禪與台詞
| 用語 | 場合 |
|------|------|
| **Kroniichiwa!** | 招呼用語（Kronii + konnichiwa） |

## 遊戲角色設定要點（同人遊戲製作用）

### 核心概念
- **時間的化身** — Kronii是時間本身的存在，具有控制時間流動的能力
- **秩序 vs 混沌** — 作為秩序的代表，與混沌（Bae）形成宿敵關係
- **時空一體** — 與空間（Sana）是互補的存在

### 能力設定方向
1. **時間操控** — 加速、減速、暫停時間
2. **預知** — 作為時間的看守者，某種程度上能看見時間的流向
3. **劍術** — 設定中「反射性地拿起雙刃」，擅長劍術
4. **時空聯動** — 與空間能力者有組合技的可能性

### 角色性格指南
- **表層**：冷靜、自信、自戀、毒舌、理性
- **裡層**：容易慌亂、自我懷疑、運氣差、有反差萌
- **台詞風格**：乾澀的幽默、自誇後立刻被打臉、遊戲中發出誇張叫聲
- **關鍵轉折點**：完美的表象崩壞時展現的真實面貌，是最具戲劇性的瞬間

### 與其他角色的互動模板
| 角色類型 | 互動模式 |
|----------|----------|
| 自然系角色（Fauna） | 友誼深厚，但經常互相捉弄 |
| 混沌系角色（Bae） | 宿命對立，嘴上吵架但實為好友 |
| 空間系角色（Sana） | 最佳搭檔，時空合體技 |
| 文明系角色（Mumei） | 朋友間的輕鬆鬥嘴 |

### 視覺標誌元素
- 沙漏（⌛）主題飾品
- 藍白金色調
- 軍裝風格外套
- 武士刀／雙刃
- 時鐘齒輪圖案
- 銜尾蛇象徵
