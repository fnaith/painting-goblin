# 大空スバル (Oozora Subaru) — 性格・配信スタイル・人际关系调查报告

> 调查日期: 2026-06-21
> 所属: ホロライブプロダクション (Hololive Production) 2期生
> 出道日: 2018年9月16日
> 角色设计: Shigure Ui

---

## 一、基本设定

大空スバル的官方设定是综合格斗部 (MMA) 与 e-sports 部的经理。她以"男勝り"(假小子)的性格著称，与任何人都不分彼此地接触，是一个开朗、充满活力且活泼的女孩。

- 自我介绍: **「ちわーす! ホロライブ2期生大空スバルっス! !」**
- 英文开场白: **"Sup! I'm Oozora Subaru!"**
- 年龄设定: 约18-20岁
- 粉丝名称: **スバ友 (Suba-tomo / Subaru's friends)**，英语圈也称 "Subaru's Army"
- 直播标签: **生スバル**

---

## 二、性格特征

### 核心特质
| 特征 | 描述 |
|------|------|
| **外向活泼** | 精力充沛，像太阳一样照耀周围的人 |
| **假小子 (男勝り)** | 运动系性格，不拘小节 |
| **努力家** | 对游戏技术精益求精，不断练习 |
| **乐观积极** | 永远保持笑容和正向态度，鼓励观众 |
| **善于交际** | 与任何人都能毫无隔阂地交流 |

### 反差萌 (Gap Moe)
スバル的魅力之一在于巨大的性格反差。表面上是一个运动型、外向的"超人"形象，但她也经常表现出：
- **笨拙 (ドジ)** — 有时会犯糊涂、冒冒失失
- **容易害羞** — 被夸奖时会不好意思
- **少女的一面** — 与朋友互动时常流露出女性化的一面
- **天然呆** — 意外的呆萌行为让观众发笑

### 社交角色
她在团体中经常担任 **ツッコミ (吐槽役)** 的角色，自然地在对话中承担吐槽职责，被同伴们戏称为喜剧演员。但本质上她有一颗金子般的心，让周围的人都感到舒适和被关爱。

### MBTI 人格类型
普遍认为スバル属于 **ESFP (外向、感觉、情感、感知)** 类型，即"表演者/艺人"型人格。这类人以表现力丰富、 spontaneity (自发性) 和对生活的热爱为特征。

### 绰号
- **ホロライブの太陽 (Hololive的太阳)** — 因为她用笑容和正能量照亮所有人
- **Subachan** — 粉丝昵称

## 三、声音特征

- **沙哑嗓音 (ハスキーボイス)** — 这是スバル最具辨识度的标志性特征，在VTuber中非常独特
- 歌声优美 — 粉丝常称赞她唱歌时拥有美丽的嗓音
- 独特的笑声和咳嗽声也让粉丝感到亲切

## 四、配信风格与游戏类型

### 配信内容分类
1. **游戏实况** — 主要配信内容，尤其是竞技类游戏
   - FPS 类 (如 Apex Legends)
   - 各类竞技游戏
   - 单机游戏
   - 水平不断提升，自称"绝赞练习中"
2. **杂谈配信** — 与粉丝轻松聊天，适合学习或做其他事时当背景音
3. **Collaboration 联动配信** — 与其他 Hololive 成员合作
4. **歌回/Karaoke** — 唱歌配信，展示其歌唱力
5. **活动/企划** — 参加 Hololive 官方大型活动

### 配信风格特点
- **高能量** — 始终保持活力充沛的状态
- **互动性强** — 积极与观众沟通，"Suba-tomo，let's go!" 等口号拉近与观众距离
- **努力家气质** — 即使游戏打得不好也坚持不懈，将失败视为学习机会
- **真诚不做作** — 展现出真实的自己，让观众产生亲切感
- **正向激励** — 经常鼓励观众拥抱生活，积极面对困难

## 七、"Subaru's Army" 粉名起源

スバル的粉丝在日语圈被称为 **スバ友 (Suba-tomo、Subaru's friends)**，而在英语圈则常被称为 **"Subaru's Army" (スバル軍)**。这个名称来源于：
- 她运动系、经理人的设定自然衍生出"军队/团队"的比喻
- 粉丝像军队一样团结支持她
- 她积极向上的领导力气质让粉丝愿意追随
