## 二、官方世界觀設定（同人遊戲核心素材）

### 種族：半精靈半塞壬
- **父親**：精靈（Elf）
- **母親**：塞壬（Siren，希臘神話中以歌聲誘惑水手的海妖）
- 因此同時擁有精靈的長耳朵和塞壬的魅惑歌聲

### 來歷
- 來自**異世界**，故鄉名為**「シャルイース」（Sha-Le-Ys）**
- 「Aki Rosenthal」**並非本名**——是 Yagoo（Cover CEO）為了讓地球人容易發音而取的名字
- 因為好奇心旺盛，無法抵抗任何感興趣的探索，因此來到地球

### 浮遊雙馬尾
- 標誌性的雙馬尾透過神祕力量漂浮在空中
- 官方設定：這是名為**「Aik」**的AI搭載型自由變形飾品
- 連接到另一個次元

### 大腿次元傳送門
- 能夠從大腿之間產生各種物體和材料
- 這個「傳送門」的本質至今不明
- 是粉絲社群中的經典梗

### Yagoo 的關聯
- Yagoo 親自為她命名「Rosenthal」
- Yagoo 原本對 Hololive 的構想是「來自不同平行世界的直播主聚集在一起」——Aki 的設定完美符合這個原始概念

## 三、個人性格特質（角色塑造素材）

### 正向特質
- **聲音治癒**：聲音沉穩溫柔，初期以 ASMR 為主
- **擅長舞蹈**：目標是成為「世界第一位虛擬肚皮舞者」，原創曲《シャルイース》MV 展示了肚皮舞
- **體能不錯**：Ring Fit Adventure 表現良好
- **擅長料理**：有料理直播
- **擅長打鼓**：擁有自己的鼓組
- **持有證照**： certified Aromatherapy Instructor（芳療指導員）

### 反差/搞笑特質
- **極度膽小**：玩恐怖遊戲時尖叫連連，自稱「職業尖叫者」
- **方向感極差**：非常容易迷路
- **運氣不好**：經常遇到倒楣事，看起來有點笨拙
- **酒豪**：熱愛啤酒和日本酒，常在直播中飲酒
- **黃色幽默**：外表沉穩冷靜，但有不為人知的黃色笑話和爸爸笑話面向（夏色祭多次指出Aki其實更「黃」）
- **公開承認觸手癖好**

### 口癖
- 「Alona！」——獨特問候語
- 「おつたーる」——獨特道別語
- 「乾杯！Cheers！！」——直播開始的定番

## 四、經典迷因與精華事件（遊戲梗素材）

### ★ ムキロゼ（Mukiroze）—— 最大人氣爆點
- 在《ARK: Survival Evolved》中使用的過度肌肉男 Avatar
- 特色：幾乎全裸，只用審查褲遮擋
- 經典操作：徒手馴服迅猛龍、在烈日下裸體生存一整天、懸崖邊無陷阱馴服大型恐龍
- ムキロゼ的誕生讓許多人發現 Aki 並成為粉絲，顯著提升觀看數
- **同人遊戲素材**：可作為隱藏角色、變身型態、或召喚技能

### ★ 浮遊雙馬尾可拆卸
- *Holo no Graffiti* 動畫中顯示雙馬尾是可拆卸配件（對應官方設定「AI搭載型飾品Aik」）
- 其他成員可以取下、傳遞甚至當工具使用

### ★ 「生出大空昴」迷因
- *Holo no Graffiti* 短片中，Aki 從大腿次元傳送門拉出大空昴
- 粉絲稱之為「生出/分娩大空昴」，鞏固了大腿傳送門的惡搞形象

### ★ 「沒有鼻子」迷因
- 早期 Live2D 模型鼻子不明顯，粉絲以此玩梗
- Reddit 上曾有系列貼文「shitpost until she gets a nose」

### ★ 其他梗
- **大腿傳送門**（如上所述）
- **雙馬尾連接異次元**
- **ムキロゼじゃんけん**：參加角卷綿芽晨間節目的猜拳環節，被認為無法擊敗
- **VCR GTA 活動**：成為幫派老大「NEO POLICE」，獲得「モンド殺し」（Mondo Killer）稱號

## 六、同人遊戲設定素材整理

### 可直接使用/改編的核心要素

| 素材 | 遊戲化建議 |
|------|-----------|
| **半精靈半塞壬血統** | 種族技能樹：精靈敏捷 + 塞壬魅惑/歌聲魔法 |
| **浮遊雙馬尾 (Aik)** | 可成長的 AI 裝備 / 飛行能力來源 / 武器 |
| **大腿次元傳送門** | 道具欄系統 / 召喚技能 / 搞笑演出 |
| **ムキロゼ** | 隱藏角色 / 狂暴變身 / 召喚獸 |
| **異世界「シャルイース」** | 遊戲主線關鍵地點 / 劇情核心／故鄉 |
| **肚皮舞** | 角色專屬技能 / Buff 技能 / 特殊演出 |
| **ASMR 治癒之聲** | 回復技能 / 魅惑技能 / 我方全體 Buff |
| **酒豪設定** | 醉酒 Buff/Debuff 系統 / 狀態異常 |
| **膽小 + 尖叫體質** | 遇到恐怖事件時的搞笑反應演出 |
| **方向感極差** | 地圖探索中的搞笑台詞 / 迷路事件 |
| **「Alona」問候語** | 角色專屬台詞 / 技能詠唱咒文 |
| **蘋果 (🍎) 代表符號** | 角色標誌 / 粉絲勢力象徵 |
| **ロゼ隊（蘋果騎士）** | 粉絲勢力的 NPC 形象：戴面罩的浮游蘋果生物 |

### 可作為劇情靈感的事件
1. **交通事故/住院** → 角色過去創傷或劇情轉折點
2. **收益化被取消** → 逆境中奮起的劇情
3. **聲帶手術** → 失去/恢復力量的劇情
4. **Yagoo 命名** → 角色真實身份相關的伏筆
5. **用手機出道（無電腦）** → 艱苦創業的背景故事
