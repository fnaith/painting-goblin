## 一、官方設定 / 角色背景

### 官方介紹文
> 大學生，同時從事模特兒與偶像工作，後來對VTuber產生了興趣。

### 雙重人格設定（核心特徵）
Moona 最具特色的官方設定為 **「一人之中有兩個靈魂」**：

| 人格 | 聲線 | 性格 | 備註 |
|------|------|------|------|
| **Moona** | 高音、像小孩的可愛聲線 | 開朗陽光、偶像人格 | 日常直播的主人格 |
| **Hoshinova** | 低沉、御姐聲線 | S属性、月之女神、有施虐傾向 | 偶爾出現的裏人格 |

官方Q&A：
> 「為什麼有時候聲音不一樣？——因為這個身體裡有兩個人。如果你聽到像小孩子的高音，那是Moona；如果聽到像大姊姊的低音，那大概是Hoshinova。」

### 視覺設計
- **主題**：月亮 / 星辰 / 太空偶像美學
- **主色調**：白、藍、銀色（月亮意象）
- **服裝**：不對稱白藍裙裝、過膝長靴、星星/月亮裝飾、choker
- **頭髮**：銀白色長髮、漸層藍色髮尾、側編髮
- **眼睛**：藍紫色
- **配件**：新月髮飾、星星飾品
- **角色設計者**：Nyori（nyorinyori），與其他VTuber（月並ナト、雨天ひより、星降いく、幸ねみや）共享同一繪師

### 服裝型態
- 原始2D Live模型（2020年4月出道）
- 3D模型（2020年12月初公開；2022年3月hololive 3rd fes正式亮相）
- 多套替換服裝（隨活動逐步公開）

## 二、角色個性 / 言行特徵

### 核心性格
- 出道時害羞安靜，但迅速成長為自信活潑的表演者
- **笑聲像海豚**——已成為粉絲間的迷因
- 食量大，常在直播吃東西；特別喜歡起司漢堡
- 喜歡講冷笑話、在Twitter發迷因
- 隨機、無法預測——官方描述為「pretty random」
- 玩遊戲時會陷入沉默、高度專注
- 自稱「我是偶像，不是搞笑藝人」（官方Q&A回答）

### 稱呼與語言

| **語言** | 印尼語、英語、日語 — 三語直播 |

- **歌唱**：強勁的歌唱實力，發行多首原創曲，擁有自己的Official Artist Channel

### 🌟 Pekora x Moona（ペコムーナ）— 決定性的跨組合作
- **2020年12月1日**，Pekora 到 Moona 的 HoloID Minecraft 伺服器遊玩，Moona 在直播中即時突破 300K 訂閱
- 這個連動讓 HoloID 大量曝光給日本觀眾，是 Hololive 跨語言/跨組合作的經典案例
- Pekora（混沌搗蛋）與 Moona（認真但容易慌張）的互動組合成為傳說
- 被粉絲稱為「PekoMoon」，是 Hololive 史上最重要的跨組搭檔關係之一

### 🤝 重要關係
| 對象 | 關係 |
|------|------|
| **Usada Pekora** | 跨組黃金搭檔，PekoMoon |
| **Ayunda Risu** | HoloID 1期同期生，摯友 |
| **Airani Iofifteen** | HoloID 1期同期生，Iofi曾畫多張Moona粉絲繪 |
| **Nerissa Ravencroft** | 跨組音樂合作（歌曲「100%」） |
| **Hololive ID全員** | 作為HoloID前輩積極參與組內活動 |

### 📺 經典場面 / 迷因素材
1. **Pekora Minecraft連動** — 300K即時達成，Hololive歷史性時刻
2. **Hoshinova降臨** — 低沉S聲線出現時聊天室暴動，被視為「月之女神來訪」
3. **企鵝Pororo** — 直播中出現的企鵝布偶，Moona極度佔有慾：「你可以看，但不能摸。他是我的。」
4. **海豚笑聲** — 粉絲公認的特色笑聲，已成為迷因定型
5. **#GrassMoona** — 迷因標籤，Moona本人積極參與迷因文化
6. **Moona Boona** — 與Risu、Iofi合作的印尼鬼故事系列，國內外粉絲都喜愛
7. **冷笑話Twitter** — 定期在Twitter發布諧音梗、無厘頭觀察

### 🎭 其他有趣軼事
- **粉絲名雙關**：MoonaFic 音同日語/印尼語的「munafik」（偽善者），Moona 自己也會開玩笑說要改成「MoonaFridge」
- **生日巧合**：2月15日與天文學家伽利略同一天生日；姓氏「Hoshinova」由日語「hoshi」（星）+ 拉丁語「nova」（新）組成
- **自製Cover**：多首Cover曲由Moona親自處理樂器、混音、插畫、剪輯，展現技術力
- **前模特兒**：出道前是雜誌模特兒，與一般VTuber「宅/遊戲玩家」出身形成反差
- **網路問題**：出道初期網路很差，有時得用手機網路直播
- **不喜歡番茄**：設定上不喜歡番茄（トマト）
- **「我是偶像」**：官方Q&A被問是不是搞笑藝人時回答「不，我是偶像」——粉絲認為對比她的天然呆行為格外可愛

## 四、遊戲設定活用建議

### 可活用元素
1. **雙重人格（Moona / Hoshinova）** → 可作為角色技能切換/覺醒系統的設計核心
2. **月之女神/宇宙偶像主題** → 世界觀、視覺風格、能力設定的基調
3. **PekoMoon搭檔關係** → 可作為劇情搭檔或支援角色登場
4. **HoloID一期生羈絆** → Risu、Iofi可作為夥伴角色
5. **Minecraft建築師設定** → 角色可能擅長「構築/創造」類技能
6. **三語能力** → 對話系統可以展現多語言要素
7. **海豚笑聲、企鵝Pororo、冷笑話** → 搞笑日常場景的素材
8. **#GrassMoona 迷因文化** → 角色與玩家的互動機制參考
