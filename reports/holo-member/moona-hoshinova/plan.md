# Research Plan: Moona Hoshinova (Hololive Indonesia)

## Main Research Question
Hololive ID member Moona Hoshinova 的相關資料，包含官方設定/個人特色/相關軼事等，用於製作同人遊戲的設定

## Subtopic 1: Official Setting & Character Design
- VTuber model design, theme, and official lore
- Hololive ID generation info, debut date, agency background
- Catchphrases, official taglines, and channel branding
- Target: character sheet / profile for game reference

## Subtopic 2: Personality & Personal Characteristics
- Personality traits, quirks, and speech patterns
- Skills, talents, and claimed abilities
- Fanbase name, community traditions
- Viewer interaction style and streaming habits
- Target: dialogue style and character behavior reference

## Subtopic 3: Notable Anecdotes & Milestones
- Key collaborations (especially with other Hololive members)
- Viral moments, memorable streams, achievements
- Rivalries, friendships, and group dynamics
- Career milestones (subscriber milestones, 3D debut, etc.)
- Target: event/scenario ideas for game setting

## Synthesis Approach
Compile findings into a structured character profile reference suitable for game development, organized by visual design, personality, and story/lore elements.
