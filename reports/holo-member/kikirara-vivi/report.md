## 二、官方角色設定

### 角色定位
FLOW GLOW 的**化妝擔當（メイク担当 / Makeup Artist）**，一位追求「真正之美」的求道者。

### 個性描述
- 一旦發現能讓自己變得更美的東西，就會坐立不安、無法克制
- 情感表達直接、毫不掩飾，說話不時夾帶**關西方言（関西弁）**
- **天敵是直射陽光**——自稱長期室內生活讓肌膚狀況保持得很好
- 外表華麗辣妹風，內在卻有直率親切的「おバカ」反差萌

### 官方自我介紹
> 「いつも、キラキラな、綺々羅々ヴィヴィです！」（永遠閃閃發亮的綺綺羅羅薇薇！）

### 開場招呼
> 「んーーーーーー...ヴィヴィ！」(拖長音的招牌開場)

### 結束語
> 「んーーーーーー...ヴィヴィ！おつヴィヴィ！」

### キャッチフレーズ（標語）
> 日文：「ちょい待ってぇな、あんたんこと変えたるから！」
> 英文：「Hol'up, 'cus you're in for a transformation!」
> 中文：「等一下啦，我要把你改造一番！」

## 三、外觀與服裝設計

### 預設服裝（Designer: nonco）
- **主題色**：粉紅、紫色、白色為主，搭配金色飾品
- **髮型**：雙馬尾，紫粉挑染
- **風格**：街頭潮流辣妹系（ギャル），結合哥德&流行元素
- **標誌配件**：墨鏡（可取下）、大蝴蝶結、荷葉邊裝飾
- **妝容**：精緻強烈，呼應化妝師身份

### 其他造型
- **holonatsu Paradise 衣裝**（Designer: Chyan）
- **FLOW GLOW 表演服**（Designer: Nowri）

### 遊戲角色設計建議（視覺面）
- 可將「墨鏡」作為辨識度高的標誌性裝備，在遊戲中可設計摘下/戴上的表情差分
- 妝容與美妝主題可融入技能系統（如 buff 技能命名為「ヴィヴィメイク」）
- 雙馬尾與華麗飾品適合做為角色剪影的識別特徵

## 四、個性與直播風格（角色性格參考）

### 說話方式
- 明亮高音、元氣滿滿的嗓音
- 語尾習慣性拖長（「んーーー...」）
- 關西方言交雜，語氣直率不修飾
- 情緒起伏大，笑聲與驚呼反應豐富

### 直播風格
- **耐久歌回**（耐久カラオケ）為招牌內容形式
- 雜談直播自然率真，與觀眾互動積極
- 與 FLOW GLOW 成員（Isaki Riona、Koganei Niko、Mizumiya Su、Rindo Chihaya）默契極佳

### 遊戲角色設計建議（性格面）
- 台詞設計可加入關西腔風格的直率語氣
- 角色可設定為「美妝狂熱者」+「室內派」的組合
- 在遊戲中對「陽光」「紫外線」等元素有特殊反應（例如弱點或嫌惡）
- 戰鬥或互動台詞可加入「んーーー...」的拖長音口癖

## 九、同人遊戲設定要點總結

### 角色關鍵詞
化妝師 / 關西腔 / 室內派 / 耐久歌回 / キラキラ / 墨鏡 / 雙馬尾 / 反差萌 / 3D ライブ / Holiday Cup 優勝

### 可強化的遊戲元素
1. **視覺素材豐富**：多套官方服裝（含新年造型）可作為遊戲造型參考；3D模型有完整動作參考
2. **技能系統靈感**：美妝 buff、耐久歌回範圍技、自製道具 crafting、Holiday Cup 風格競技技能
3. **對話風格明確**：關西腔直率口吻 + 「んーーー...」拖長音口癖 + 對美麗的執著 + 「おつヴィヴィ！」結束語
4. **互動關係素材**：FLOW GLOW 同團成員、Pekora（Minecraft 合作）、白銀ノエル等合作對象可作為 NPC
5. **角色弱點設計**：陽光/紫外線天敵、對化妝品無法抗拒、討厭苦味食物
6. **特殊反應**：遇到炸雞或蜜柑時觸發喜愛反應；提到美妝活動時觸發熱情模式
