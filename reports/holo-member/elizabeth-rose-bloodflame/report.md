## 5. 故事背景與Lore

### 角色Lore
來自「Great Exardia」（推測影射Great Britain）。她是人類。雖有「深紅女王」之稱，但並非皇族後裔。她是Justice的領導者，被派遣追捕逃亡中的Advent期成員。據點是「The Lookout」總部，配有「The Panscope」（多維望遠鏡）。

### 敘事連結
- **Advent VS Justice（#AdVSJus）**: 4集動態漫畫系列，Justice（獵人）vs Advent（逃亡者）的追逐劇情。Elizabeth為Justice方的獵人角色。
- **ENigmatic Recollection**: Hololive EN集體Minecraft RPG劇情活動（Starmine開發），Elizabeth參與第3章「Broken Bonds」。
- **holoPop NEXUS**: 在美國紐澤西舉辦的pop-up活動。
- **Justice團隊設定**: Justice的會議室名為「The Lookout」，位於Justice總部。團隊擁有吉祥物「Sergeant Smokey」，偶爾會下達命令。Justice有權任命第五名成員（但為臨時職位，「像換襪子一樣頻繁更換」）。Cecilia Immergreen曾被強迫在Justice擔任女僕工作。
- **Cockney腔**: Elizabeth是標準RP（Received Pronunciation）英語使用者，但為了角色扮演學習了Cockney方言。著名的Cockney特徵包括省略h音（"Ello"而非"Hello"）以及「bottle of water」發音為「BO-OH-O-WO-ER」。

### 與其他成員關係
- **Nerissa Ravencroft（Advent）**: Elizabeth對她有「not-so-secret appreciation」（公開的秘密欣賞）
- **同期Justice**: Gigi Murin、Cecilia Immergreen、Raora Panthera — 緊密的團隊關係
- **Kureiji Ollie（ID）**: Elizabeth的kami-oshi（最喜歡的推）

## 6. 同人遊戲製作建議

### 可用遊戲類型
根據 **Age of Advent** 的先例（Hololive官方支持的免費迷你遊戲合集），Justice主題遊戲有類似潛力：

**選項A：Justice迷你遊戲合集**
- Elizabeth → 唱歌/節奏遊戲
- Gigi → 動作/搞笑遊戲
- Cecilia → 解謎/智力遊戲
- Raora → 繪畫/創意遊戲

**選項B：Elizabeth主角單一遊戲**
- 動作冒險或角色扮演遊戲
- 其他Justice成員為支援角色

### 個性 → 遊戲機制對應表
| 個性特質 | 遊戲機制 |
|---------|---------|
| 午睡恢復 | 休息/Nap機制 — 快速回復HP/MP，但睡眠中脆弱 |
| 聲音模仿 | 偽裝/減益技能 — 模仿敵人迴避，或模仿友軍buff |
| 美麗歌聲 | 吟遊詩人職業 — 範圍buff；節奏遊戲強化效果 |
| 戲劇性flair | 超華麗終結技動畫 |
| 自我要求嚴格 | 風險回報機制 — 消耗HP換取巨大傷害 |
| 領導力 | 隊伍領袖被動 — 全體隊友buff；同伴AI指令 |
| 戰鬥+唱歌雙重能力 | 雙職業切換 — 戰士模式（物理）⇄ 吟遊詩人模式（歌曲buff） |
| 火焰/血主題 | HP作為資源 — 消耗HP發動強力火焰攻擊 |
| 深紅/玫瑰色調 | UI主題、粒子效果統一紅色系 |

### 視覺/美術方向
- 像素風（參考Age of Advent）
- 主色調：深紅、黑、白、藍色火焰點綴
- 玫瑰圖騰、火焰特效、皇冠標誌
- Rosarian吉祥物作為同伴/收集要素

### 音樂/音效資源
可使用她的原創曲作為BGM：
- 「RENEGADE」 — 戰鬥/高能量場景
- 「Odyssey」 — 史詩/旅程主題
- 「ABOVE BELOW」 — 團體場景
- 「All for One」 — 團隊合作主題
- 「START AGAIN」 — 新開始/重生
- 「Serendipity」 — 2026年原創曲，同名音樂會主題曲
- 「SUPERNOVA SUPER GIRL」 — 2026年原創曲，高能量超級英雄風

### 開發注意事項
- **Cover Corp同人遊戲規範**於2023年11月公布
- **holo indie** 標籤支援Steam發行
- 目前尚無以Elizabeth為主角的同人遊戲 — 這是早期優勢
- 同人遊戲社群活躍於 Game Jolt、Itch.io、Steam
