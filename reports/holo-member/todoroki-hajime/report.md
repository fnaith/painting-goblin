## 三、角色性格設定（核心設定重點）

### 3.1 核心矛盾：「番長」 vs 「赤ちゃん」
這是她最關鍵的角色魅力，必須在遊戲中體現：

| 番長面（偽裝） | 赤ちゃん面（真實） |
|--------------|-----------------|
| 自稱「宇宙第一番長」 | 行動完全不像番長 |
| 想表現得很帥氣 | 做什麼都可愛 |
| 喜歡裝酷 | 天然呆、無邪氣 |
| 口號：「ブンブンバンチョー！」 | 不自覺發出「バブ〜」（嬰兒語） |
| 目標是成為Badass | 被全員當成寶寶照顧 |

**遊戲應用**：對話選項可設計「番長模式選擇」——選番長回應但效果會因天然而歪樓，或者選擇誠實的柔軟反應。

### 3.2 性格細項

| 性格 | 說明 | 遊戲應用 |
|------|------|---------|
| **元氣滿滿** | 永遠精力充沛，坐不住 | 移動速度偏快，跑步動畫活潑 |
| **純真無邪** | 反應直接純粹，不擅長說謊 | 對事件的反應很直接，容易上當 |
| **天然呆** | 經常說出意外的爆笑發言 | 對話中設計「天然選擇肢」 |
| **笨手笨腳** | 道具使用苦手、料理災難級 | 遊戲中不能讓她做料理/精密操作 |
| **感動屋** | 容易被溫情場面弄哭 | 好感度事件中會有感人反應 |
| **照れ屋** | 不善面對誇獎和粉絲藝術 | 被稱讚時會臉紅結巴 |
| **お茶目** | 喜歡惡作劇、會自己笑到停不下來 | 特定情境下觸發搞笑事件 |

### 3.3 口癖與台詞風格

| 類型 | 台詞 | 使用時機 |
|------|------|---------|
| **登場台詞** | 「ブンブンバンチョー！押忍！」 | 登場/自我介紹 |
| **英語版** | 「Vroom vroom vroom! Resident badass, Todoroki Hajime!」 | 帥氣場合（但英文很破） |
| **嬰兒語** | 「バブ〜」 | 放鬆/開心/撒嬌時不自覺說出 |
| **招牌口號** | 「はじめの名にかけて！」 | 下定決心時 |
| **害羞時** | 「え、ちょ、待って！」 | 被誇獎時 |
| **驚嚇時** | 「うわあああっ！」 | 驚嚇反應 |

## 五、經典梗與迷因（遊戲彩蛋素材）

### 5.1 はじめ語（Bancho語言）
- **描述**：她獨特的發音體系，連日本人都聽不懂
- **梗點**：Siri 無法識別她的語音
- **遊戲應用**：可設計「翻譯はじめ語」小遊戲，或在對話中出現完全無法理解的台詞（付費DLC：はじめ語辭典）

### 5.2 サカバンバスピス（Sacabambaspis）
- **描述**：她無法正確說出「Sacabambaspis」（一種古代魚）這個詞
- **梗點**：粉絲認為這條魚長得像她
- **遊戲應用**：可作為收集要素中的隱藏魚類

### 5.3 番長 vs お姫様
- **描述**：她自稱番長，但她媽媽叫她「お姫様」（公主）
- **遊戲應用**：可在遊戲中安排媽媽來電場景

### 5.4 紫色寶寶（Purple Baby）
- **描述**：與 Hololive EN 的 Koseki Bijou (Biboo) 同為紫色系嬰兒角色
- **遊戲應用**：如果加入EN角色，可設計「紫色寶寶同盟」

### 5.5 ネームク星人（Namekian）
- **描述**：粉絲玩笑稱她其實是《七龍珠》的那美剋星人
- **遊戲應用**：隱藏彩蛋——特定條件下觸發那美剋星人梗

### 5.6 其他知名梗
- 「チョコポメラニアンのうた」— 她自創的謎之歌，可作為遊戲BGM彩蛋
- 体重を平然と暴露 — 會不在意地透露自己的體重
- コールセンター勤務の過去 — 曾在客服中心工作過（背景故事素材）

## 八、同人遊戲角色設計建議

### 角色定位選項
1. **主角**：以はじめ為主角，講述她從「自稱番長」成長為「真正番長」的故事
2. **夥伴**：作為遊戲中元氣担当的夥伴角色，提供搞笑場面和活力
3. **可攻略對象**：在戀愛模擬元素中，她可走「番長路線」或「赤ちゃん路線」

### 推薦遊戲類型
- **視覺小說/冒險遊戲**：最適合呈現她豐富的對話和表情變化
- **節奏遊戲**：搭配她的原創歌曲和舞蹈能力
- **生活模擬**：體驗她的日常（包含料理災難）

### 角色技能樹提案
1. **番長技能線**：威嚇、領導力、格鬥（但效果總是歪樓）
2. **舞蹈技能線**：節奏遊戲加分、表演技能
3. **交流技能線**：はじめ語（讓對方困惑）、バブー（讓對方心軟）

### 關鍵設計要素
- **對話系統**：必須包含豐富的表情變化（Q版和立繪）
- **はじめ語彩蛋**：一定數量的無法解讀台詞
- **バブー系統**：特定情境下觸發「バブ」選項
- **ギャップ表現**：番長台詞 vs 實際行動的反差演出
