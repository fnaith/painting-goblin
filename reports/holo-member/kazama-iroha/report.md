## 二、官方設定（適合遊戲角色背景）

### 角色背景
來自偏遠山區的鄉下，為了追求夢想、見識外面的世界，帶著隨從踏上了武者修行的旅程。現在以保鏢身份受僱於秘密結社holoX，賺取生活費。

### 角色台詞
- 「holoXの用心棒、侍の風真いろはでござる」
- 「お待たせしました! こんにちはでござる」
- 「I daresay」

### 服裝設計要素
- 武士/忍者風格（綠白配色）
- 攜帶武士刀
- 有眼鏡造型變化
- 多套服裝：初始服裝、新年和服、第三套服裝、泳裝等

## 三、性格特質（適合遊戲角色塑造）

### 核心性格
| 特質 | 說明 |
|------|------|
| **認真負責** | 設定上是認真的武士，對工作盡責 |
| **忠誠** | 對holoX和同伴忠誠不二 |
| **天然呆** | 不時表現出冒失可愛的一面（ギャップ萌え） |
| **古風** | 使用武士口調「でござる」，有古風氣質 |
| **好勝** | FPS遊戲實力頂尖，有好勝心 |

### 說話風格
- 古風用語，句尾常加「でござる」
- 自我介紹必定強調「用心棒侍」
- 語氣認真但有時會露出可愛的一面

### 特技
- **FPS遊戲**：Hololive頂尖FPS玩家，擅長Apex Legends等射擊遊戲
- **劍術**（設定上）：作為武士的設定技能
- **歌唱**：歌聲清澈有力，有多首原創曲

## 四、同人遊戲活用建議

### 角色定位建議
- **職業**：武士/保鏢/忍者
- **屬性**：風（名字中的「風真」）、綠
- **武器**：武士刀（近戰）、手裡劍（遠程）
- **角色類型**：認真系但帶有天然呆屬性的戰士

### 可能的故事線
1. **武者修行**：從偏遠山村到大城市的成長故事
2. **保鏢任務**：保衛holoX總部或重要人物的任務
3. **與同伴的羈絆**：與holoX成員（La+、Lui、Koyori、Chloe）的互動
4. **ギャップ萌え**：嚴肅外表下的可愛日常

### 可用的遊戲內台詞
- 「でござる！」（戰鬥吶喊）
- 「お待たせしました！」（登場）
- 「風真いろは、推して参る！」（粉絲互動）
- 「我が刀、受けてみよ！」（戰鬥）
